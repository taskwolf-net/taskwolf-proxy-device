# Dulno - Proxy - Device

[![CI](https://github.com/taskwolf-net/taskwolf-proxy-device/actions/workflows/ci.yml/badge.svg)](https://github.com/taskwolf-net/taskwolf-proxy-device/actions/workflows/ci.yml)

This module enables the smooth running of device functions within the Dulno network. In particular, it regulates the coordination between the individual nodes. Without this module, a direct connection to the individual devices would not be possible
